 راهنمای نصب سایت Yacin Photo روی هاست Node.js
═══════════════════════════════════════════════

روش سی‌پنل (Setup Node.js App):
1. فایل‌ها را در public_html (یا پوشه اپ) آپلود و Extract کنید
2. در سی‌پنل → Setup Node.js App:
   - Node.js version: 18 یا بالاتر
   - Application root: مسیر پوشه پروژه
   - Application URL: دامنه شما
   - Application startup file: server.js
3. روی Run NPM Install بزنید
4. در بخش Environment variables این‌ها را اضافه کنید:
   NODE_ENV = production
   PORT = 3000 (معمولاً خودکار است)
5. Restart را بزنید — سایت بالا می‌آید!
6. ورود به پنل: yourdomain.com/admin
   (همان رمزی که قبلاً استفاده می‌کردید — از data/admin-password.json خوانده می‌شود)

نکات مهم:
- پوشه data و assets/uploads باید قابل نوشتن باشند (پیش‌فرض سی‌پنل اوکی است)
- هیچ دیتابیس جداگانه‌ای لازم نیست
- اگر می‌خواهید رمز را عوض کنید، دیتای admin-password.json را حذف کنید
  و متغیر ADMIN_PASSWORD را در env تنظیم کنید، بعد یکبار سرور را ری‌استارت کنید

اصلاحات نسخه جدید (انجام شد):
- جاوااسکریپت: نوشتن اتمی فایل‌های دیتا (اگر سرور وسط ذخیره خاموش شود، دیتا خراب نمی‌شود)
- فرم تماس: ضد اسپم (هانی‌پات) + محدودیت ۵ پیام در ۱۰ دقیقه برای هر IP
- هدرهای امنیتی CSP و HSTS اضافه شد
- کش درست شد: بعد از تغییر محتوا در پنل، بازدیدکننده‌ها فوراً نسخه جدید را می‌بینند
- favicon.ico واقعی + og-cover.jpg ساخته شد (پیش‌نمایش شبکه‌های اجتماعی درست می‌شود)
- فایل "my logo.png" به "my-logo.png" تغییر نام داد (فاصله در نام فایل برای وب خطرناک است)
- خاموشی امن سرور (SIGTERM) + مدیریت خطاهای سیستمی
- وابستگی‌ها به‌روز شد (0 آسیب‌پذیری)
